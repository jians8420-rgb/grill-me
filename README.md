# Grill Me

A standalone, repository-local Codex skill adapted from [Matt Pocock's skills](https://github.com/mattpocock/skills), licensed under MIT.

This fork keeps one invokable skill: `grill-me`. Its original `grilling` dependency is included directly in [SKILL.md](.agents/skills/grill-me/SKILL.md).

## Use in this repository

Open this repository in Codex and invoke `$grill-me` (or choose **Grill Me** from the skill picker). The skill interviews you in rounds to clarify a plan or design.

## Use in another repository

Copy `.agents/skills/grill-me/` into that repository's `.agents/skills/` directory, then open the repository in Codex and invoke `$grill-me`.
